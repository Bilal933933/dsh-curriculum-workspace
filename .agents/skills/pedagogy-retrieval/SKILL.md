# مهارة الاسترجاع التربوي (pedagogy-retrieval)

## 1. الغرض
تحويل سؤال المعلّم التربوي — «كيف أدرّس القراءة؟»، «ما الطريقة الاستقرائية؟»،
«كيف أصوغ اختبارًا موضوعيًّا؟» — إلى **صفحة محدَّدة** في كتب الطبقة التربوية،
ثم قراءة سياقها والاستشهاد بها.

**الطبقة التربوية = معرفة تربوية** (طرائق، استراتيجيات، كفايات، تقويم، مناشط)،
وليست حزم دروس ولا مقررًا مدرسيًّا.

## 2. متى تُستدعى
- سؤال في طرق تدريس اللغة العربية أو مهاراتها (محادثة/استماع/قراءة/كتابة).
- سؤال في الأهداف العامة وأهداف التدريس، أو الكفايات اللغوية.
- سؤال في التقويم وصوغ الاختبارات الموضوعية.
- سؤال في إدارة الصف والمناشط اللغوية اللاصفية.
- سؤال لغوي مساند (سمات العربية ولطائفها) عند الحاجة إلى خلفية للمعلّم.

## 3. تحديد النطاق
- النطاق **محصور** بالكتب التي تحمل في `meta/catalog.yaml` الحقل:
  `collection: pedagogy`.
- **لا** تُستدعى هذه المهارة لسؤال مقرر مدرسي (تلك مهمة `curriculum-retrieval`).
- كتب الأضواء وأمثالها مراجع خارجية مساعدة، ولا تُستشهد بدل المقرر.

| الكتاب | id | ملاحظة |
|---|---|---|
| طرائق تدريس اللغة العربية (1) | `pedagogy_ar_tr1` | الخصائص والأهداف والكفايات وطرائق تدريسها |
| طرائق تدريس اللغة العربية (2) | `pedagogy_ar_tr2` | التعبير والنحو والإملاء والأدب والتقويم والمناشط |
| من سمات اللغة العربية ولطائفها | `pedagogy_ar_simat` | خلفية لغوية للمعلّم |
| في رحاب لغتنا العربية | `pedagogy_ar_lugha` | مرجع لغوي/نقدي مساند |
| استراتيجيات تدريس اللغة العربية (مكتب التربية العربي) — المجلدات 1–3 | `pedagogy_ar_strategies` | استراتيجيات وتقويم؛ الملف مجموع ثلاثة مجلدات بترقيم مُعاد ⇒ لا إزاحة واحدة |

**قاعدة:** لا تعتمد على هذا الجدول؛ `meta/catalog.yaml` هو المصدر الوحيد، فاقرأه أولًا
وخذ الكتب التي `collection: pedagogy`، ومساراتها من `text_dir` و`index_dir`.

## 4. خطوات التنفيذ

### الخطوة 1 — تحديد الكتاب
اقرأ `meta/catalog.yaml`، ورشّح الكتب بـ`collection: pedagogy` بحسب الموضوع:
- طرائق/مهارات → `tr1` ثم `tr2`.
- التعبير/النحو/الإملاء/الأدب/الاختبارات/المناشط → `tr2`.
- استراتيجيات وتقويم موسّع → `strategies`.
- خلفية لغوية → `simat` / `lugha`.

### الخطوة 2 — تطبيع عبارة البحث
```powershell
python scripts/retrieval/normalize.py "الطريقة الاستقرائية"
# ← الطريقه الاستقرائيه
```

### الخطوة 3 — تضييق النطاق من `toc.yaml`
افتح `meta/books/<id>/toc.yaml`، وحدّد الفصل والموضوع، وخذ نطاق `from`/`to`
ورقم صفحة الموضوع. لا تبحث في الكتاب كله بلا داعٍ.

### الخطوة 4 — المطابقة المعجمية
```powershell
$idx = "index\<text_dir-من-catalog>\norm"     # استخدم index_dir الفعلي
$q = python scripts/retrieval/normalize.py "الطريقة الاستقرائية"
Select-String -Path "$idx\*.txt" -Pattern $q -Encoding UTF8 |
  Select-Object -First 20 | ForEach-Object { $_.Filename }
```
- إن لم توجد نتائج للعبارة المركّبة، جرّب **أقصر جزء دالّ** (`الاستقرائيه`).
- العنوان قد يسبقه ترقيم (`١- الخصائص الصوتية`)، فلا تشترط سطرًا كاملًا.
- عند تعدّد النتائج، ابدأ بالصفحات داخل نطاق الموضوع من `toc.yaml`.

### الخطوة 5 — القراءة والتحقق
افتح الصفحة الأصلية كاملة قبل الجواب:
```powershell
Get-Content "output\<book>\page_037.md" -Encoding UTF8
```
**لا تجب من الملف المطبَّع**؛ الاقتباس الحرفي من الأصل المشكَّل.

### الخطوة 6 — الاستشهاد
1. اقرأ `printed_page_offset` من `meta/catalog.yaml` (أو `manifest.json`).
2. **إن كان رقمًا** (`-1` في كتابَي طرائق): «ص = رقم الملف + الإزاحة».
   مثال: الموضوع في `page_010` ⇒ «طرائق تدريس اللغة العربية (1) — ص ٩».
3. **إن كان `unknown`** (مثل «من سمات» و«في رحاب» و«استراتيجيات»): اذكر رقم الملف وحده:
   «ملف `page_010`»، ولا تحوّله إلى رقم مطبوع.
   - في «استراتيجيات» الملف ثلاثة مجلدات، ولكل مجلد إزاحة داخلية مختلفة؛ ذكر **اسم المجلد** مع رقم الملف.
4. لا تُطبّق إزاحة كتاب على آخر، ولا تخمّن إزاحة.

## 5. متى ننتقل إلى الشاملة (MCP)؟
| الحالة | القرار |
|---|---|
| نتيجة محلية تُجيب السؤال | الجواب من الكتاب فقط |
| صفر نتائج بعد التطبيع وتجربة جزء أقصر | الشاملة |
| سؤال عن خلاف تربوي أو أقوال متعددة | الشاملة، مع تمييز المستويين |
| حاجة إلى أصل شرعي/تراثي (توجيه، أدب نفس) | الشاملة |
| صفحة ناقصة | يُعلَن النقص، ثم تُستكمل مع التنبيه |

قناتا الاستدعاء: `mcp__shamela__*` أو `python scripts/retrieval/shamela_client.py find "..."`.
استشهد برابط `citation.markdown`.

## 6. حدود وإجراءات وقائية
- **ممنوع** تعديل `curriculum_raw/` أو `output/` أو `index/` يدويًّا.
- **ممنوع** اختلاق صفحة أو نسبة قول إلى مؤلف لم تقرأه.
- الطبقة التربوية **لا تُعارض** المقرر المدرسي؛ إن طلب المستخدم حكم المقرر فارجع إلى
  `curriculum-retrieval`، واجعل التربوي طبقة مساندة معلَّمة المصدر.
- «الأضواء» كتاب خارجي مساعد، لا يُستشهد به بدل المقرر.
- عند اختلاف كتابَي طرائق (1) و(2) في المسألة نفسها، اذكر الاثنين بموضعهما.

## 7. الصيانة
بعد إضافة كتاب تربوي جديد:
```powershell
python scripts/retrieval/onboard_book.py --book "<المجلد>" --id <id> --title "<العنوان>"
# راجع toc.draft.yaml ثم اعتمده toc.yaml، واضبط collection: pedagogy وprinted_page_offset
python scripts/validate_all.py
```
