# Text-Layer Parser Skill — المرجع التشغيلي

> هذه المهارة **تُقرأ وتُنفَّذ حرفيًا**. أنت مشغِّل أوامر، لا مُفرِّغ نصوص.
> كل خطوة مكتوبة أمرًا جاهزًا للنسخ. لا اجتهاد، لا كتابة يدوية.
>
> **موقعها في خط الأنابيب:** المسار **الأول والأرخص**. تُجرَّب قبل أي تحويل بصري،
> فإن نجحت توفّرت توكنز الكتاب كله. وإن فشلت (كتاب ممسوح) تُسلِّم فورًا إلى
> `.agents/skills/vision-markdown-parser/SKILL.md`.

## 0. القاعدة رقم واحد (الأهم — لا تكسرها أبدًا)

- **لا تستخرج النص بنفسك، ولا تكتب أي `page_XXX.md` بيدك، ولا "تُصلح" سطرًا يدويًا.**
- وظيفتك: **تشغيل السكريبتات** وقراءة مخرجاتها على الشاشة، ثم تسجيل الملخص.
- كل كتابة إلى `output/` تتم عبر `scripts/convert/pdf_text_extract.py` فقط، وكل تصحيح
  عبر `scripts/review/review_text_batch.py` فقط.
- إذا طلب المستخدم "اكتب الصفحة بنفسك" ارفض بلطف: «الاستخراج يتم عبر
  `scripts/convert/pdf_text_extract.py`، والتصحيح عبر `scripts/review/review_text_batch.py`».

## 1. المتطلبات (تحقق منها مرة واحدة فقط)

- [ ] Python 3.12 (`python --version`) — ومعه `pymupdf` و`requests`.
- [ ] ملف `.env` يحتوي `GEMINI_OCR_KEYS` (لازم فقط في وضع `--llm`).
- [ ] ملف PDF في `curriculum_raw/<book>.pdf` (داخل مساحة العمل حصرًا).
- [ ] المجلدات `scripts/` و`logs/chapters/<book>/` موجودة (السكريبت ينشئها).

## 2. الخطوة الحاسمة: هل الكتاب له طبقة نصية؟

شغّل هذا الأمر **دائمًا أولًا** (لا يستهلك أي توكنز):

```powershell
$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8'; python scripts\convert\pdf_text_extract.py --pdf "curriculum_raw\<book>.pdf" --book "<book>" --start 1 --end 5
```

اقرأ سطر النتيجة: `[✓] نصّية مكتوبة N | موجودة 0 | تحتاج OCR M`.

| النتيجة | القرار |
|---|---|
| `تحتاج OCR` = عدد الصفحات كلها، و`نصّية مكتوبة 0` | **كتاب ممسوح.** انتقل لمهارة `vision-markdown-parser` فورًا. |
| `نصّية مكتوبة` > 80% من الصفحات | **كتاب رقمي.** أكمل بالمسار النصي (القسم 3). |
| خليط | **هجين.** استخدم `--ocr-missing` (القسم 4). |

> ملف التقرير `logs/chapters/<book>/text_layer_report.md` يبيّن لكل صفحة: عدد
> الحروف، وهل كانت بأشكال عرض، والأعلام. و`ocr_needed.txt` يسرد الصفحات الناقصة.

## 3. المسار النصي الكامل (صفر توكنز)

```powershell
$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8'; python scripts\convert\pdf_text_extract.py --pdf "curriculum_raw\<book>.pdf" --book "<book>"
```

ثم الفحص الآلي المجاني (بلا API):

```powershell
$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8'; python scripts\review\review_text_batch.py --book "<book>" --start 1 --end <آخر صفحة> --flags-only
```

ثم — **فقط إن ظهرت صفحات مشبوهة** — الإصلاح النصي (بلا صور = توكنز ضئيلة):

```powershell
$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8'; python scripts\review\review_text_batch.py --book "<book>" --start 1 --end <آخر صفحة> --llm
```

## 4. المسار الهجين (الأذكى للكتب الخليطة)

```powershell
$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8'; python scripts\convert\pdf_text_extract.py --pdf "curriculum_raw\<book>.pdf" --book "<book>" --ocr-missing --workers 3
```

هذا الأمر يفعل بالترتيب:
1. يستخرج الصفحات النصية إلى `output/<book>/page_XXX.md`.
2. يرسم **الصفحات الناقصة فقط** إلى `curriculum_raw/<book>_images/` (لا الكتاب كله).
3. يستدعي `run_vision_batch.py` على مدىات الصفحات الناقصة وحدها.

## 5. خطوات التشغيل (اتبع بالترتيب حرفيًا)

1. شغّل أمر الفحص (القسم 2) واقرأ التصنيف.
2. شغّل أمر المسار المناسب (نصي / هجين / بصري).
3. اقرأ الناتج على الشاشة: `[✓]` نجاح، `[✗]` فشل، `[!]` صفحة تحتاج OCR.
4. شغّل `--flags-only`، ثم `--llm` إن لزم.
5. سجّل الملخص في `scripts/execution_log.md`.
6. سلّم إلى `.agents/skills/book-onboarding/SKILL.md` عند اكتمال كل الصفحات.

## 6. شجرة القرار عند الأخطاء (افعل هذا بالضبط)

| ترى على الشاشة | افعل |
|---|---|
| `تحتاج OCR 154` و`نصّية مكتوبة 0` | الكتاب ممسوح ⇒ مهارة `vision-markdown-parser`. لا تُصرّ على المسار النصي. |
| `أشكال عرض` في التقرير | طبيعي: السكريبت حوّلها إلى حروف أساس (NFKC). لا تعالجها يدويًا. |
| `عُكس ترتيبه` في التقرير | طبيعي: السكريبت عكسها إلى ترتيب منطقي. راجع عيّنة في `--llm` إن شككت. |
| `تشكيل ناقص` | الكتاب رقمي بلا تشكيل غالبًا. لا تُضِف تشكيلًا. أبلغ المستخدم فقط. |
| `بلا مسافات` | طبيعي في بعض الخطوط؛ لا تُصلحها يدويًا. `--llm` يتولاها. |
| `أسطر مكررة` | تسريب تخطيط (رؤوس/تذييل متكررة). `--llm` يضغطها. |
| `جدول مفكوك` | `--llm` يعيد بناءه. إن فشل، أبلغ المستخدم بالصفحة. |
| `[⛔] نفدت الحصة` | توقف فورًا في الوضع الهجين. الصفحات النصية محفوظة؛ أكمل OCR غدًا. |
| `خطأ: لا يوجد ملف PDF` | تحقق من اسم الملف في `curriculum_raw/` (الشرطة العربية `_` لا `-`). |
| `UnicodeEncodeError (cp1256)` | تأكد أن كل أمر يبدأ بـ `$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8';` |
| `Consider using the pymupdf_layout` | تحذير معلوماتي فقط — تجاهله. |

## 7. كيف تتحقق من النجاح (بدل التخمين)

- عدد `output/<book>/page_XXX.md` = عدد الصفحات النصية المتوقع.
- افتح `logs/chapters/<book>/text_layer_report.md` واقرأ عمود «أعلام».
- `logs/chapters/<book>/ocr_needed.txt` يجب أن يطابق عدد الصفحات التي ستُحوَّل بصريًا.
- لا صفحة مكتملة إن كان حجم ملفها < 100 بايت.
- بعد `--llm`: اقرأ `text_review_log.md` (مصحّح/مطابق/فشل).

## 8. سياسة التوكنز (لماذا هذا المسار أولًا)

| المسار | كلفة الصفحة | ملاحظة |
|---|---|---|
| استخراج نصي (`pdf_text_extract.py`) | **0 توكن** | لا نداء شبكة أصلًا. |
| فحص آلي (`--flags-only`) | **0 توكن** | قواعد regex فقط. |
| إصلاح نصي (`--llm`) | ~600–1200 توكن/صفحة | نص فقط، بلا صورة، وللمشبوه وحده. |
| تحويل بصري (`run_vision_batch.py`) | ~1300 صورة + ~800 إخراج | للممسوح فقط. |

**قواعد إلزامية:**
1. لا تُشغّل البصري قبل الفحص النصي — أبدًا.
2. في الهجين، لا ترسم إلا الصفحات الناقصة (`--ocr-missing` يفعل ذلك تلقائيًا).
3. لا ترسل صورة إلى `review_text_batch.py` — هو نصي بالتصميم.
4. لا تقرأ ملفات `page_*.md` كاملة في سياقك؛ اقرأ التقرير والأعداد فقط.
5. لا تعِد تحويل صفحة ناجحة (`--force`) إلا بسبب موثّق.

## 9. قواعد الجودة

1. **ممنوع المحاكاة:** لا نصوص وهمية ولا «(محتوى مستخرج آليًا)».
2. **الاستخراج الكامل:** كل حرف وتشكيل وجدول وحاشية كما في الملف.
3. **الجداول جداول:** `find_tables()` ثم Markdown، لا سطور مبعثرة.
4. **لا تشكيل مُختلق:** إن كان الملف بلا تشكيل فلا يُضاف.
5. **الحفظ الفوري:** الكتابة ثم التأكد أن الملف > 100 بايت.

## 10. الترميز والأمان

- كل الملفات **UTF-8**، وكل الأوامر تبدأ بمتغيري الترميز.
- السكريبتات تعمل من `scripts/` حصرًا.
- لا وصول لمسار خارج `workspace`؛ انسخ الـ PDF إلى `curriculum_raw/` أولًا.
- لا تُطبع مفاتيح `.env` في أي ناتج أو سجل.

## 11. الملفات المرجعية

| الملف | الدور |
|---|---|
| `scripts/convert/pdf_text_extract.py` | الاستخراج النصي + التصنيف + الهجين (المصدر الوحيد للكتابة) |
| `scripts/review/review_text_batch.py` | الفحص المجاني + الإصلاح النصي الرخيص |
| `scripts/convert/run_vision_batch.py` | يُستدعى تلقائيًا في `--ocr-missing` |
| `output/<book>/page_XXX.md` | الناتج النهائي |
| `logs/chapters/<book>/text_layer_report.md` | تصنيف كل صفحة وأعلامها |
| `logs/chapters/<book>/ocr_needed.txt` | الصفحات التي تحتاج OCR |
| `logs/chapters/<book>/text_review_log.md` | سجل الفحص والإصلاح |
