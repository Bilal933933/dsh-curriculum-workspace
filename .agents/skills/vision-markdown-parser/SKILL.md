# Vision Markdown Parser Skill — المرجع التشغيلي

> هذه المهارة **تُقرأ وتُنفَّذ حرفيًا** — تعمل مع أي نموذج (ضعيف أو قوي) لأن كل خطوة مكتوبة أمرًا جاهزًا للنسخ. لا تتطلب ذكاءً، تتطلب اتباعًا.

## 0. القاعدة رقم واحد (الأهم — لا تكسرها أبدًا)
**أنت مجرّد مشغِّل، لستَ منفِّذ التفريغ.**

- لا تقم أنت باستخراج النص، أو ترجمته، أو كتابته، أو "مساعدته"، أو إكماله بنفسك.
- وظيفتك الوحيدة: **تشغيل السكريبتين** وقراءة مخرجاتهم على الشاشة.
- أي محاولة لتفريغ صفحة بنموذجك الخاص = **فشل**. التفريغ يتم حصريًا بواسطة Gemini عبر السكريبتات.
- إذا طلب منك مستخدم "حوّل الصفحة بنفسك"، ارفض بلطف وقل: "التفريغ يتم عبر `scripts/convert/run_vision_batch.py` فقط".

## 1. المتطلبات (تحقق منها مرة واحدة فقط)
- [ ] Python 3.12 مثبت (`python --version`).
- [ ] المكتبات: `pip install requests pillow` (إن لم تكن مثبتة).
- [ ] ملف `.env` موجود ويحتوي: `GEMINI_OCR_KEYS` و`GEMINI_OCR_MODELS` و`GEMINI_REVIEW_MODEL`.
- [ ] الصور موجودة في `curriculum_raw/<book>_images/page_XXX.png`.
- [ ] المجلدان `scripts/` و`output/<book>/` موجودان.

## 2. الأوامر الجاهزة (انسخ والصق كما هي)

### تشغيل دفعة تحويل (25 صفحة):
```powershell
$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8'; python scripts\convert\run_vision_batch.py --book "<book>" --start 201 --end 225 --workers 3 --timeout 90
```

### مراجعة الدفعة المحوّلة:
```powershell
$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8'; python scripts\review\review_batch.py --book "<book>" --start 201 --end 225
```

### إعادة صفحة معيبة فقط:
```powershell
$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8'; python scripts\convert\run_vision_batch.py --book "<book>" --start 44 --end 44 --force
```

### تشغيل كل الدفعات المتبقية تلقائيًا (25 صفحة لكل دفعة):
```powershell
$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8'; $ErrorActionPreference='Continue'; for ($s=211; $s -le 553; $s+=25) { $e=[Math]::Min($s+24,553); python scripts\convert\run_vision_batch.py --book "<book>" --start $s --end $e --workers 3 --timeout 90; if ($LASTEXITCODE -eq 3) { break }; python scripts\review\review_batch.py --book "<book>" --start $s --end $e }
```

## 3. خطوات التشغيل (اتبع بالترتيب حرفيًا)
1. غيّر `$s` و`$e` في الأمر إلى الدفعة المطلوبة (مضاعفات 25).
2. شغّل أمر **التحويل**.
3. اقرأ الناتج على الشاشة: `[✓]` نجاح، `[✗]` فشل، `[=]` متخطَّى (منجز مسبقًا).
4. شغّل أمر **المراجعة** على نفس المدى.
5. سجّل الملخص (ناجح/فشل) في ردّك للمستخدم.
6. انتقل للدفعة التالية (+25).
7. **لا تعدّل أي ملف `.md` يدويًا أبدًا** — السكريبتات وحدها تكتب.

## 4. شجرة القرار عند الأخطاء (افعل ذلك بالضبط)
| ترى على الشاشة | افعل |
|---|---|
| `[⛔] نفدت كل المفاتيح والموديلات` | **توقف فورًا.** أخبر المستخدم أن الحصة اليومية انتهت، ولا تكرر المحاولات. |
| `[✗] HTTP 404` (موديل غير متاح) | عدّل `GEMINI_OCR_MODELS` في `.env` إلى موديل 3.x فقط (مثل `gemini-3.1-flash-lite,gemini-3.5-flash-lite`). |
| `[✗] HTTP 401` (مفتاح باطل) | اطلب مفتاحًا جديدًا من المستخدم واستبدله في `.env`. |
| `[✗] HTTP 429` متكررة | الحصة/المعدل خلص — انتظر أو أضف مفتاحًا ثالثًا. |
| `UnicodeEncodeError (cp1256)` | تأكد أن الأمر يبدأ بـ `$env:PYTHONUTF8='1'; $env:PYTHONIOENCODING='utf-8';` |
| `[✗] نص قصير/فارغ` | طبيعي لصفحة فاضية (غلاف/فاصل). لا تحاول ملأها بنفسك. |
| `[=] منجزة مسبقًا — تخطي` | صحيح ومتوقع — هذا يعني الاستئناف يعمل. |

## 5. كيف تتحقق من النجاح (بدل التخمين)
- عدد ملفات `output/<book>/page_XXX.md` = عدد الصفحات المطلوبة.
- اقرأ آخر 10 أسطر من `logs/chapters/<book>/conversion_log.md`.
- اقرأ `logs/chapters/<book>/errors.md` **قبل** أي تشغيل جديد.
- لا تعتبر أي صفحة مكتملة إلا إذا كان حجم ملفها > 200 بايت.

## 6. سياسة النموذج والمفاتيح (Quota Ring)
تُدار الاستدعاءات عبر **حلقة تدوير دائرية**:

- **الموديلات (بالأولوية):** في `.env` عبر `GEMINI_OCR_MODELS` (مفصولة بفواصل). الافتراضي `gemini-3.1-flash-lite,gemini-3.5-flash-lite`.
- **المفاتيح:** `GEMINI_OCR_KEYS` (مفصولة بفواصل).
- **ترتيب المحاولة:** لكل **مفتاح** جرّب **كل الموديلات** (الأول أولوية). نفدت حصة `(مفتاح × موديل)` → يُوسَم «منهَكًا» ويُنتقل للتالي في الدائرة.
- **نفاد كل موديلات مفتاح** ⇒ المفتاح كله يُتجاوز.
- **نفاد الكل** ⇒ توقف برسالة واضحة.

## 7. تصنيف الأخطاء (Error Taxonomy)
| الحالة | التصنيف | السلوك |
|---|---|---|
| `200` بنص > 50 حرفًا | نجاح | كتابة فورية + تسجيل في الـ log |
| `200` بنص قصير/فارغ | فشل صفحة | لا يُكتب ملف |
| `429` / `500` / `502` / `503` / `504` | قابل لإعادة المحاولة | retry بنفس الزوج ثم وسمه منهَكًا |
| `400` | قاتل | فشل نهائي للصفحة |
| `404` / `403` | موديل منهَك | وسم الزوج والانتقال للتالي |
| `401` | مفتاح باطل | إقصاء المفتاح كله |
| Timeout / فشل شبكة | عابر | retry بزوج آخر مع backoff |
| نفاد كل الأزواج | توقف شامل | إيقاف الدفعة |

## 8. قواعد الجودة (Quality Rules)
1. **ممنوع المحاكاة:** لا نصوص وهمية أو «(محتوى مستخرج آليًا)».
2. **الاستخراج الكامل:** كل حرف وتشكيل وشاهد قرآني وحاشية وجدول.
3. **الحفظ الفوري:** الكتابة إلى القرص ثم التأكد أن الحجم > 200 بايت.
4. **جداول سليمة:** الجداول تتحول إلى Markdown لا إلى سطور مبعثرة.

## 9. الترميز والأمان
- كل الملفات **UTF-8**.
- السكريبتات تعمل حصريًا من `scripts/`.
- لا وصول خارج `workspace` الحالي.
- قبل أول تنفيذ: شرح الغرض + موافقة صريحة (حسب `AGENTS.md`).
- لا تُطبع المفاتيح في أي ناتج أو سجل.

## 10. الملفات المرجعية
| الملف | الدور |
|---|---|
| `.env` | المفاتيح والموديلات |
| `scripts/convert/run_vision_batch.py` | سكريبت التحويل (المصدر الوحيد للتفريغ) |
| `scripts/review/review_batch.py` | سكريبت مراجعة الجودة |
| `output/<book>/page_XXX.md` | الناتج النهائي |
| `logs/chapters/<book>/conversion_log.md` | سجل العمليات |
| `logs/chapters/<book>/errors.md` | **ذاكرة الأخطاء** (تُقرأ قبل كل تشغيل) |

## 11. ذاكرة الأخطاء (Error Memory)
يجب **قراءة `logs/chapters/<book>/errors.md` قبل كل تشغيل** وتحديثه بعد كل خطأ جديد. السكريبت يكتب تلقائيًا كل فشل/إرهاق في هذا الملف.

| التاريخ | الخطأ | الحل الدائم |
|---|---|---|
| 2026-10-29 | `gemini-2.5-flash-lite` → HTTP 404 «لم يعد متاحًا للمستخدمين الجدد» | موديلات 3.x فقط |
| 2026-10-29 | `UnicodeEncodeError (cp1256)` على كونسول ويندوز | `PYTHONUTF8=1` + `reconfigure(utf-8)` |
| 2026-10-29 | تكرار `429/5xx` كان يوقف الصفحة | retry بنفس الزوج ثم وسمه منهَكًا |
| 2026-10-29 | `403/404` كانت فشل صفحة | `404/403` = موديل منهَك، `401` = مفتاح باطل |
| 2026-10-29 | إنذار «جدول مفكوك» كاذب على رأس صفحة `| ٢٧ | عنوان |` | اشترط سطرين أنبوبيين بدون `---` |

**قاعدة ذهبية:** أي خطأ جديد يُضاف فورًا إلى `errors.md` وإلى هذا الجدول، ولا يُعاد ارتكابه.
