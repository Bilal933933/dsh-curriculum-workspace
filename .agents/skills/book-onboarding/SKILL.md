# مهارة تسجيل كتاب جديد (book-onboarding)

## 1. الغرض
بعد أن ينتهي تحويل كتاب جديد إلى `output/<book>/page_XXX.md`، هذه المهارة **تُدخله
في طبقة الاسترجاع** كي يصبح قابلًا للبحث والاستشهاد مثل بقية الكتب:
سجل المصادر ← الفهرس المعجمي ← خريطة الموضوعات.

## 2. متى تُستدعى
- اكتمل تحويل كتاب جديد (صور ⇢ Markdown).
- أُضيف كتاب لم يكن في `meta/catalog.yaml`.
- أُعيد تحويل كتاب تغيّر عدد صفحاته (لتحديث إحصاءاته).

## 3. المتطلبات المسبقة
| المتطلب | التحقق |
|---|---|
| مخرجات التحويل | `output/<book>/page_XXX.md` موجودة |
| صور الصفحات | `curriculum_raw/<book>_images/` (لعدّ الإجمالي) |
| المصدر PDF | `curriculum_raw/<book>.pdf` (مستحسن بقوة — يجعل الصور قابلة لإعادة التوليد) |
| سكريبت الفهرس | `scripts/retrieval/build_index.py` موجود |

## 4. التنفيذ — خطوة واحدة

```powershell
python scripts\retrieval\onboard_book.py `
  --book "كيف_تتقن_الصرف" `
  --id sarf `
  --title "كيف تتقن الصرف؟" `
  --author "أحمد إسكندر" `
  --subject "الصرف" `
  --publisher "دار اللؤلؤة للنشر والتوزيع — المنصورة، مصر"
```

**للاختبار بلا أي كتابة** أضف `--dry-run` (يطبع الإحصاءات ويتحقق من عدم التكرار فقط).

### ما يفعله السكريبت
1. **يتحقق:** وجود المخرجات، عدد الصفحات، الفجوات، عدد الصور، وجود PDF.
2. **يمنع التكرار:** إن كان `--id` مسجّلًا في `catalog.yaml` يتوقف برسالة (لا يضيف مدخلًا ثانيًا).
3. **يسجّل:** يضيف مدخلًا للكتاب في `meta/catalog.yaml` قبل قسم `external_sources`.
4. **يفهرس:** يبني `index/<book>/norm/` عبر `build_index.build_book()`.
5. **يولد مسوّدة:** `meta/books/<id>/toc.draft.yaml` من عناوين الكتاب.

### الملفات التي يقرأها
`output/<book>/*.md`، `curriculum_raw/<book>_images/`، `curriculum_raw/<book>.pdf`، `meta/catalog.yaml`.

### الملفات التي يكتبها
`meta/catalog.yaml`، `index/<book>/…`، `meta/books/<id>/toc.draft.yaml`.

> لا يمسّ `curriculum_raw/` ولا `output/` (قراءة فقط).

## 5. الخطوات البشرية المتبقية (إلزامية)

المسوّدة **لا تُستخدم قبل المراجعة**؛ لذلك تبقى بامتداد `.draft`:

1. **راجع `toc.draft.yaml`:** احذف غير الدالّ، صحّح العناوين، وأضف `keywords` لكل فصل
   (مصطلحات مُطبَّعة بلا تشكيل — هي أساس التضييق السريع).
2. **اعتمدها:** أعد تسمية الملف إلى `toc.yaml`، واحتفظ بـ `reviewed: false` حتى تنتهي المراجعة.
3. **حدّث المهارة:** أضف المعرّف الجديد إلى قائمة `<id>` في
   `.agents/skills/curriculum-retrieval/SKILL.md`.
4. **سجّل:** أضف سطرًا في `scripts/execution_log.md`.

## 6. بعد مراجعة الجودة
إن عدّلت مراجعة الجودة نصوص `output/` لاحقًا، **أعد بناء الفهرس** (ثوانٍ، بلا كلفة):

```powershell
python scripts\retrieval\build_index.py --book "<اسم مجلد الكتاب>"
# أو كل الكتب:
python scripts\retrieval\build_index.py
```

## 7. قيود وتحذيرات
- **لا تُشغّل السكريبت قبل اكتمال التحويل:** الفجوات تُسجَّل كصفحات ناقصة، وتصبح بيانات السجل مغلوطة.
- **`--id` لاتيني قصير** (`balagha`/`nahw`/`sarf`) لأنه مسار مجلد ومرجع في `catalog.yaml`.
- **`--book` بالعربية** كما هو اسم المجلد الحقيقي في `output/`.
- إن لم يوجد PDF للكتاب فالسجل يسجّل `source_pdf: null`، وتصبح **الصور هي المصدر الوحيد** — لا تحذفها حينئذ.
- المسوّدة آلية: قد تخطئ في تمييز «الفصل» من «المبحث»، فالمعيار النهائي هو مراجعتك.
