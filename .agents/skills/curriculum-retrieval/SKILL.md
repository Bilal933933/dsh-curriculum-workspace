# مهارة الاسترجاع من المنهج (curriculum-retrieval)

## 1. الغرض
تحويل سؤال المستخدم — في البلاغة أو النحو — إلى **صفحة محدَّدة** في الكتب المحوَّلة،
ثم قراءة سياقها والاستشهاد بها. المهارة هي «الطبقة المحلية» من نظام المصادر:
المنهج أولًا، ثم المرجع التراثي (الشاملة MCP) عند نقص البيانات.

## 2. متى تُستدعى
- سؤال في علم المعاني أو البيان أو البديع أو النحو أو الصرف.
- طلب شرح قاعدة، أو تعريف مصطلح، أو شاهد قرآني/شعري من الكتاب.
- استخراج تدريب أو إجابة من الكتاب المقرَّر.

## 3. البنية التي تعتمد عليها

| المسار | الوظيفة |
|---|---|
| `meta/catalog.yaml` | فهرس الكتب: العنوان، المؤلف، المسار، التغطية |
| `meta/books/<id>/toc.yaml` | خريطة الفصول والموضوعات → نطاقات صفحات ومصطلحات |
| `index/<book>/norm/page_XXX.txt` | نص الصفحة مُطبَّعًا (بلا تشكيل ولا فروق إملائية) |
| `output/<book>/page_XXX.md` | النص الأصلي المُشكَّل — هو المرجع للقراءة والاقتباس |
| `index/<book>/manifest.json` | الصفحات الناقصة والمتفرقة |

- `<id>` مفتاح لاتيني قصير يُستخدم في مسار `meta/books/<id>/` وفي حقل `id` بالمرجع.
  **لا توجد قائمة معرّفات محفوظة هنا** — اقرأ القائمة الحالية من `meta/catalog.yaml` كل مرة،
  فالتسميات تتغيّر (مثلًا `arabic_p1_t1` بجانب `adwaa_ar_p1_t1`) والقائمة الثابتة تتقادم بصمت.
- `<book>` **اسم المجلد العربي كما هو**: `كيف_تتقن_البلاغة` أو `كيف_تتقن_النحو` أو `اللغة_العربية_الصف_السادس_ت1`.
  استخدم حقل `text_dir` و`index_dir` من `catalog.yaml` بدل تخمين المسار.
- **قاعدة:** `meta/catalog.yaml` هو المصدر الوحيد للعنوان و`id` و`text_dir`، فاقرأه أولًا ولا تخمّن.

## 4. خطوات التنفيذ

### الخطوة 1 — تحديد الكتاب
اقرأ `meta/catalog.yaml` وحدّد `id` الكتاب. إن تصلّح السؤال للمادتين فاستخرج من كليهما.

### الخطوة 2 — تطبيع عبارة البحث
النص مُشكَّل، فلا تبحث بالعبارة كما هي:

```powershell
python scripts/retrieval/normalize.py "الاستعارة المكنية"
# ← الاستعاره المكنيه
```

### الخطوة 3 — تضييق النطاق من `toc.yaml`
ابحث عن الموضوع في خريطة الفصل، وخذ نطاق الصفحات (`from`/`to`) وصفحة الموضوع.
هذه الخطوة تمنع البحث في 550 صفحة بلا داعٍ.

### الخطوة 4 — المطابقة المعجمية
```powershell
$book = "كيف_تتقن_البلاغة"          # من catalog.yaml (حقل text_dir/index_dir)
$q = python scripts/retrieval/normalize.py "الاستعارة المكنية"
Select-String -Path "index\$book\norm\*.txt" -Pattern $q -Encoding UTF8 |
  Select-Object -First 20 | ForEach-Object { $_.Filename }
```
- إن كانت العبارة مركّبة وبلا نتائج، جرّب **أقصر جزء دالّ** منها (`المكنيه` بدل الجملة كاملة).
- العنوان في الكتاب قد يسبقه ترقيم (`١ - الحَالُ`)، فلا تشترط مطابقة سطر كامل؛ اعتمد على `toc.yaml` للصفحة، ثم اقرأها للتحقق.
- عند تعدّد النتائج، ابدأ بالصفحات الواقعة داخل نطاق الموضوع من `toc.yaml`.

### الخطوة 5 — القراءة والتحقق
افتح الصفحة الأصلية كاملة قبل أن تجيب:
```powershell
Get-Content "output\$book\page_298.md" -Encoding UTF8
```
**لا تجب من الملف المطبَّع**؛ فقد حُذف منه التشكيل وعلامات الترقيم، والاقتباس الحرفي يكون من الأصل.

### الخطوة 6 — الاستشهاد
كل معلومة تُنسب صراحةً، ومعها الرقم المطبوع **إن عُرف**:

1. اقرأ `printed_page_offset` من `index/<book>/manifest.json`.
2. **إن كان رقمًا** (مثل `-1`): «كيف تتقن النحو؟ — ص ٣١٦ (ملف `page_317`)» مع المسار.
   الحساب: `رقم المطبوع = رقم الملف + الإزاحة`.
3. **إن كان `unknown`**: اذكر رقم الملف وحده: «… — ملف `page_317`» مع المسار، **ولا تحوّله** إلى رقم مطبوع.

لا تُطبّق إزاحة كتاب على كتاب آخر، ولا تخمّن إزاحة غير معلنة. الإزاحة قرار كل كتاب على حِدة، ومصدرها الوحيد `meta/catalog.yaml`.

## 5. متى ننتقل إلى الشاملة (MCP)؟

| الحالة | القرار |
|---|---|
| نتيجة محلية تُجيب السؤال | الجواب من الكتاب فقط |
| صفر نتائج بعد التطبيع **وتجربة جزء أقصر** | الشاملة |
| السؤال عن خلاف أو أقوال متعددة | الشاملة (الكتاب المدرسي واحد) |
| حاجة إلى شاهد قرآني/حديثي موثّق | الشاملة (`shamela_open`) |
| كتاب أو مؤلف غير موجود محليًّا | الشاملة |
| صفحة ناقصة (مثل `page_005` في البلاغة) | يُعلَن النقص، ثم تُستكمل من الشاملة مع التنبيه |
| تحضير المعلِّم: سؤال تعليل أو شرط أو «ولماذا؟» مع اكتمال المحلّي | الشاملة — **بإذن صريح من صاحب المشروع (2026-11-05)**، لا بالقياس |

**إذن ثابت (2026-11-05):** صاحب المشروع أجاز البحث في الشاملة **حتى مع كفاية النتيجة المحلية**، لغرض قياس القوة الإضافية وتحضير المعلِّم. هذا الإذن يُسري على الاستدعاء لا على مستوى الإجابة: الجواب للطالب يبقى من الكتاب حصرًا (§6)، وما تُضيفه الشاملة يُقدَّم طبقةً موازية معلَّمة المصدر، بلا ترجيح.

**قناتا الاستدعاء:** `mcp__shamela__*` عند توفّر الخادم في الهارنس؛ أو — في أي هارنس لا يملك الخادم — العميل النصّي المكافئ:

```powershell
python scripts/retrieval/shamela_client.py find "الكلمة الفاصلة" "كلمة ثانية" --difficulty easy
python scripts/retrieval/shamela_client.py tools          # للتحقق من الاتصال قبل أول استدعاء
```

أدوات الخادم: `shamela_find` ثم `shamela_open` (أو `shamela_open_many`). استخدم `difficulty: easy` وكلمات قليلة؛ الاستجابة كبيرة.
واستشهد برابط `citation.markdown` الذي يعيده الخادم.
**حساسية الاستعلام:** الأمثلة النحوية المجردة (`جاء زيداً`) تجرّ مواضيع من أبواب أخرى (الموصول، الإعمال)؛ استبدلها بالكلمة الفاصلة في الباب (`الإبهام`، `الهيئة`، `مزيل إبهام`) أو بلفظ المتن.

## 6. حدود وإجراءات وقائية
- **ممنوع** تعديل `curriculum_raw/` أو `output/` أو `index/` يدويًّا؛ `index/` مشتق يُعاد بناؤه بـ `python scripts/retrieval/build_index.py`.
- **ممنوع** اختلاق رقم صفحة أو نسبة قول لمؤلف لم تقرأه في الصفحة.
- إن كان السؤال عن **المقرر المدرسي** فالمصدر هو الكتاب حصرًا، ولا يُعارض بغيره.
- إذا كان الملف ناقصًا (`manifest.json` → `missing_pages`) فصرّح بذلك بدلًا من ادّعاء الشمول.
- عند تعارض الكتاب مع مرجع تراثي: اذكر الاثنين وبيّن أنهما مستويان مختلفان، ولا تُرجّح بلا دليل.

## 7. إعادة بناء الفهرس
بعد تحويل صفحات جديدة أو إضافة كتاب:
```powershell
python scripts/retrieval/build_index.py                              # كل الكتب
python scripts/retrieval/build_index.py --book "كيف_تتقن_النحو"      # كتاب واحد (اسم المجلد العربي)
```
ثم أضف الكتاب إلى `meta/catalog.yaml` وأنشئ `meta/books/<id>/toc.yaml`.
