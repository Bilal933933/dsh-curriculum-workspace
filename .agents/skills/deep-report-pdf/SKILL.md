# البحث العميق ← تقرير PDF (deep-report-pdf)

## 1. الغرض
تحويل طلب واحد («ابحث عن كذا بحثًا عميقًا») إلى **مستند PDF جاهز للطبع**:
غلاف · فهرس آلي · أقسام مرقّمة · جداول · أمثلة لكل قسم · ثبت مصادر.

## 2. متى تُستدعى
- «ابحث بحثًا عميقًا عن …» / «اجمع لي كل ما يتعلق بـ …».
- «أريد ملف PDF عن …» / «تقرير مفصّل عن …».
- «ملف مرجعي لمعلم حول …».

## 3. المسار الكامل

### أ) تفكيك السؤال قبل البحث
اكتب (لنفسك) قائمة **٦–١٠ محاور** تغطي الموضوع من كل جهة:
حدّ · أنواع · شروط · أحكام · فروق · خلاف · تطبيق · أخطاء شائعة · شواهد.
هذه المحاور ستكون أقسام المستند، فلا تبدأ البحث قبلها.

### ب) البحث
1. `shamela_find` بعبارات متعددة ومختلفة (لا كلمة مفردة، ولا السؤال كاملًا).
2. `shamela_open` / `shamela_open_many` لقراءة النص الفعلي — **المعاينة لا تكفي**.
3. `shamela_find_scoped` للمتابعة داخل الكتب المنتقاة.
4. عند الحاجة للمصادر المحلية: `output/` مع `meta/books/<id>/toc.yaml`.
5. سجّل لكل معلومة: **الكتاب + الجزء/الصفحة + الرابط**.

### ج) قواعد التحقق (قبل الكتابة)
- لا تُدرج قولًا لم تقرأ نصّه.
- التبسّ في كلمة أو رقم صفحة ⇒ افتح الصفحة، لا تخمّن.
- عند تعارض النصوص: اعرض القولين ونسبتهما، ولا تُرجّح من عندك.
- عند نقص الأدلة: اذكر المسألة غير المحسومة في موضعها.

### د) الكتابة
أنشئ `البحوث/<اسم-عربي-قصير>/report.md` بهذا القالب:

```markdown
# عنوان التقرير

## ١. تمهيد ونطاق البحث
(ما يغطيه التقرير وما لا يغطيه — ٣ أسطر)

## ٢. الحدّ والتعريف
(التعريف + سبب التسمية + جدول القيود)

## ٣. الأنواع / الأقسام
(جدول: النوع | تعريفه | مثاله)

## ٤. التفصيل
### ٤.١ …
(فقرة + مثال + مصدر)

## ٥. الأحكام والشروط
## ٦. المسائل الخلافية
(جدول: المسألة | القول الأول | القول الثاني)

## ٧. أخطاء شائعة
## ٨. خلاصة للاستعمال السريع
## المصادر
- الكتاب — ج/ص — الرابط
```

**شروط كل قسم:** عنوان مرقّمي · فقرة تعريفية · **مثال واحد على الأقل** · مصدر.
إن لم يكن للقسم مثال ⇒ القسم ناقص، لا يُكتب.

### هـ) الإخراج
```powershell
.\scripts\.venv\Scripts\python.exe scripts\documents\cli.py check --slug <الاسم>
.\scripts\.venv\Scripts\python.exe scripts\documents\cli.py make  --slug <الاسم> --author "<الاسم>" --subtitle "<سطر وصفي>"
```
الناتج: `البحوث/<الاسم>/report.pdf`.

### و) المراجعة قبل التسليم
- عدد الصفحات معقول (٦+).
- كل قسم في الفهرس موجود فعلًا في المحتوى.
- لا قسم بلا مثال، ولا معلومة بلا مصدر.
- الجداول لا تتجاوز عرض الصفحة.

## 4. قواعد الشكل
- `#` مرة واحدة (عنوان المستند — يظهر في الغلاف).
- `##` لكل قسم رئيسي (يبدأ صفحة جديدة تلقائيًّا).
- `###` للتفريعات.
- الجداول لكل مقارنة أو تعداد مرتّب.
- `>` للاقتباسات النصية الحرفية.

## 5. ممنوعات
- نصوص من الذاكرة بلا مصدر.
- حشو بلا أمثلة.
- خلط مستويات مختلفة (مبتدئ/متقدم) في القسم نفسه.
- الكتابة في `output/` أو `index/` أو `curriculum_raw/`.
