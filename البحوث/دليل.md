# البحوث — دليل الباب

باب **المستندات البحثية المطبوعة**: ملف PDF عربي منظّم لكل بحث.

## الهيكل

```
البحوث/
└─ <اسم-عربي-قصير>/
   ├─ report.md      ← المصدر (اكتبه وعدّله هنا)
   ├─ report.html    ← وسيط يُولَّد آليًّا (لا يُحرَّر)
   └─ report.pdf     ← الناتج النهائي
```

## كيف يُنشأ بحث؟

1. اكتب `report.md` وفق قالب مهارة `.agents/skills/deep-report-pdf/SKILL.md`
   (عنوان `#` واحد · أقسام `##` مرقّمة · جدول ومثال لكل قسم · ثبت مصادر).
2. افحص الجاهزية:
   ```powershell
   .\scripts\.venv\Scripts\python.exe scripts\documents\cli.py check --slug <الاسم>
   ```
3. ابنِ واطبع:
   ```powershell
   .\scripts\.venv\Scripts\python.exe scripts\documents\cli.py make --slug <الاسم> --author "<اسمك>"
   ```

## ماذا ينتج؟

| الصفحة | المحتوى |
|---|---|
| ١ | الغلاف (عنوان · عنوان فرعي · إعداد · تاريخ) |
| ٢ | فهرس المحتويات (آلي، بروابط) |
| ٣+ | الأقسام، كل قسم يبدأ صفحة جديدة |

## قواعد

1. لا تُعدّل `report.html`؛ يُعاد توليده في كل بناء.
2. العنوان يظهر في الغلاف؛ اكتبه مرة واحدة في أول سطر `# `.
3. كل قسم يحتاج **مثالًا** و**مصدرًا**، وإلا فهو ناقص.
4. المُولِّد لا يقرأ ولا يكتب خارج هذا الباب ومجلد `scripts/documents/`.
5. `نموذج_التنوين/` مثال جاهز للمعاينة — يمكن حذفه متى شئت.
