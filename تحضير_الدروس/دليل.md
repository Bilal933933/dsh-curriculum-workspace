# تحضير الدروس — دليل الباب

هذا الباب مخصّص **لمخرجات المعلم المولَّدة**، لا للمصادر.
كل ما فيه قابل للتعديل والحذف وإعادة التوليد بخلاف `output/` و`index/`.

## الهيكل

```
تحضير_الدروس/
└─ <الصف>/<المادة-الترم>/<الوحدة>/<الدرس>/
   ├─ manifest.yaml      البيان: المصادر، الحالة، التاريخ
   ├─ 01_تحضير.md        خطة سير الحصة (صفحة واحدة)
   ├─ 02_شرح_كامل.md     المادة العلمية الكاملة (٤–١٠ صفحات)
   ├─ 03_ورقة_عمل.md     تدريبات متدرجة
   ├─ 04_اختبار.md       أسئلة بلا إجابات
   ├─ 05_مفتاح_تصحيح.md  الإجابات والدرجات والأخطاء المتوقعة
   └─ 06_مذكرة_طالب.md   خلاصة الطالب (صفحة واحدة)
```

## مثال لمسار
```
تحضير_الدروس/الصف-الرابع-الابتدائي/اللغة-العربية-ت1/الوحدة-الأولى/الدرس-الثاني/
```

## وظيفة كل ملف

| الملف | لمن؟ | الطول | الوظيفة |
|---|---|---|---|
| `01_تحضير` | المعلم | صفحة | ماذا سيفعل في كل دقيقة |
| `02_شرح_كامل` | المعلم | ٤–١٠ | ما سيقوله ويعرف لماذا يقوله |
| `03_ورقة_عمل` | الطالب | صفحة–صفحتان | تدريب داخل الحصة |
| `04_اختبار` | الطالب | صفحة | تقويم بلا إجابات |
| `05_مفتاح_تصحيح` | المعلم | صفحة–صفحتان | الإجابة + الدرجة + الخطأ المتوقع |
| `06_مذكرة_طالب` | الطالب | صفحة | القاعدة في سطرين |

## القواعد

1. **المصادر أولًا:** كل ملف يبدأ بذكر صفحات كتاب الطالب التي بُني عليها.
2. **الاختبار ومفتاحه منفصلان دائمًا** — لا يُدمجان في ملف واحد.
3. **`02_شرح_كامل` هو الفرق:** فيه التفصيل والفروق والخلاف والأخطاء الشائعة، وما لا يُقال في الصف.
4. **لا تعديل في المصادر:** لا يُكتب شيء داخل `output/` أو `index/` أو `curriculum_raw/`.
5. **`manifest.yaml` إلزامي** لكل درس، وهو بيان الحزمة ومصادرها وحالتها (لا فهرس مركزي يُبنى منه).

## كيف تُولَّد الحزمة؟
نادِ مهارة `.agents/skills/teaching-pack/SKILL.md` بذكر: الصف · المادة · الوحدة · الدرس.

## الإخراج الورقي
لإخراج الحزمة كاملة كـ PDF: ادمج الملفات الستة بفواصل صفحات في `البحوث/<اسم-الحزمة>/report.md` ثم
```powershell
.\scripts\.venv\Scripts\python.exe scripts\documents\cli.py make --slug <اسم-الحزمة> --title "<اسم الدرس>" --author "<اسم المعلم>"
```
